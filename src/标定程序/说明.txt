标定程序 · 使用说明
========================================

这是什么
--------
《三角洲行动》自动化工具的「坐标标定」部分，单独拆出来的一份。
它只做一件事：把游戏界面上 16 个固定位置的屏幕坐标框出来，存进 config.json。
不点击游戏、不读内存、不联网，只是记录坐标。

需要什么
--------
- Windows 10 / 11
- Python 3.8 及以上（安装时勾选 "Add Python to PATH"）
- 不需要额外第三方库，只用 Python 自带的 tkinter

怎么用
------
1. 双击 标定.bat（或在该目录运行 python dvc_calibrate.py）
2. 屏幕会变成半透明覆盖层，右下角出现一个小面板
3. 按顺序逐项框选：
   - Ctrl + 左键单击 / 拖出一个框 = 标定当前项
   - F8 = 跳过当前项
   - Ctrl + 右键 = 回到上一项
   - Ctrl + Alt + Q = 放弃退出（config.json 不会改动）
   - 面板任意位置都能按住拖动
4. 全部框完后点「保存并结束」，结果写入同目录的 config.json

自检
----
python dvc_calibrate.py --selftest
会创建覆盖层和面板、打印 DPI / 屏幕 / 面板尺寸 / 鼠标钩子状态，然后自动关闭，不写盘。
第一次在陌生机器上用，建议先跑这个。

分辨率 / 缩放变了怎么办
----------------------
config.json 里记录的永远是「当时那块屏幕上的真实坐标」，不做任何比例换算。
换分辨率或系统缩放后，程序的标定位置会对不上，需要在新的分辨率下重新框一遍。
重新打开标定程序时，如果检测到屏幕和 config.json 里记录的不一致，
面板会黄字提示「位置对不上请逐项重新框」，并且不允许你不框任何一项就直接保存。

文件说明
--------
dvc_calibrate.py   标定界面（覆盖层 + 可拖面板 + 全局鼠标钩子）
dvc_config.py      16 个标定项的定义、配置读写、屏幕信息
config.json        标定结果（附带的这份是在 1920x1080 缩放 125% 下标定的）
标定.bat           双击启动

config.json 里 regions 的 16 个 key 依次对应：
btn_peizhuang  主菜单「配装」按钮
tab_cangku     顶部「仓库」页签
ocr_balance    右上角余额数字
scan_blank     仓库中间装备区
btn_cart       仓库购物车图标
btn_sell       仓库右下「出售」
btn_sell_ok    出售弹窗里的「出售」
slot_helmet    配装页头盔槽
slot_armor     配装页护甲槽
drag_scroll    选择页滚动条（起点 + 拖到的最底点）
click_a        选择页刷价点 A
click_b        选择页刷价点 B
ocr_price      选择页最低行价格数字
btn_buy_1      选择页购买按钮 1
btn_buy_2      选择页购买按钮 2
click_center   兜底：点屏幕中心

已知限制
--------
- 多显示器时以主屏为准
- 游戏窗口化运行时，坐标和全屏会有偏移
- 鼠标钩子可能被部分安全软件拦截；被拦时面板会红字提示
